# DayDream 大更新测试清单

需求来源：用户提供的《大更新提示词.md》。本轮只做代码核对和编译，不启动应用进行视觉或功能测试，不使用 Computer Use，不推送 GitHub。

测试包：`/Users/ty/Desktop/DayDream/DayDream.app`。请保存并退出旧版本后打开该包。

## 已确认的快捷键与翻译方式

- 笔记历史：Control + Option + ← / →。
- 左右窗格聚焦：Option + Command + ← / →。
- 关闭当前笔记：Command + W；参考窗格关闭后回到单栏，不关闭主应用窗口。
- PDF 缩放：Command + - / +（也支持 Command + =）。
- 翻译：Apple 系统翻译，无需 API Key，要求 macOS 15 或更新版本；首次使用可能提示下载语言。
- 设置提供中文、英文、日文、韩文、西班牙文、法文、德文、葡萄牙文、俄文。选择语言 A/B 后自动判断方向。

## A. 小更新与窗口修复

- [ ] 选中文字应用删除线：横线出现，文字变淡；取消删除线或重置样式后恢复。分别检查 Light/Dark 和有颜色的文字。
- [ ] 导入菜单可选 Light/Dark；分别导入 MD、PDF、Word，打开后检查所选外观。
- [ ] 从 Finder 拖入侧栏时可选导入外观；多文件只选择一次，取消不会导入。
- [ ] 导出菜单可选 Light/Dark；导出长篇 PDF 和 Word，检查背景、正文、颜色、高亮、删除线和图片。
- [ ] Markdown 导出仍保留原 Markdown 内容。其外观选择供本机 DayDream 再次打开时使用，不要求其他 Markdown 软件读取 DayDream 的外观偏好。
- [ ] PDF 初次打开留有边距；Command -/+ 连续缩放有效，滚动仍正常；切到另一份 PDF 恢复初始适配。
- [ ] Finder“打开方式 → DayDream”和拖入应用图标分别打开 MD/PDF：显示正确文件，独立窗口无侧栏，文件名居中。
- [ ] 独立 Markdown 窗口修改后关闭，重新打开确认原文件已保存；PDF 浏览不会改写原文件。
- [ ] 打开两个独立窗口与主窗口，反复切换：复制、粘贴、工具条、重置、Focus、缩放均作用于当前窗口。
- [ ] 左上角历史按钮与 Control + Option + 左右箭头工作一致；连续打开 6 份笔记，最多保留 5 条记录。
- [ ] 历史后退后打开新笔记，前进分支被替换；切换前编辑的内容正确保存，侧栏选中项跟随当前笔记。

## B. Translation Block

- [ ] `/` 菜单能搜索“翻译 / translation”；选取后进入翻译块。
- [ ] 在正文行首输入 `!!` 再按空格，同样进入翻译块。
- [ ] 输入中文后按 Enter，在下一行得到英文译文；输入英文后按 Enter 得到中文译文（以设置的语言对为准）。
- [ ] 原文保留，译文是可编辑的正文；保存、关闭、重新打开后两者仍存在。
- [ ] 翻译等待期间修改前面的段落，译文仍定位到对应翻译块；删除或修改原翻译块不会错误覆盖其他文字。
- [ ] 在设置中更换语言对，再进行翻译；不需要填写 API Key。
- [ ] 取消语言下载或翻译失败时显示说明，原文不丢失；三点菜单可取消排队中的翻译。

## C. Markdown/PDF 左侧翻译旁注

- [ ] 选中文字后右键“翻译为旁注”，或使用三点菜单的选区旁注功能；分别测试 MD 和 PDF。
- [ ] 三点菜单“全文翻译旁注”逐段生成旁注，显示在原文左边，位置与对应原文对齐。
- [ ] 旁注没有外框，默认低对比；字号与原文尽量接近，检查不同字体和 PDF 缩放倍率。
- [ ] 长译文默认截短并渐隐；鼠标悬停后向下展开，不覆盖右侧原文。
- [ ] 悬停时旁注变亮，对应原文出现低对比圆角背景；离开后恢复。
- [ ] 展开的译文遮挡其他旁注时，其他旁注模糊、淡化；收起后恢复可读。
- [ ] 滚动、调整窗口宽度、PDF 缩放之后，旁注和原文保持对应。
- [ ] 保存并重新打开同一路径的 MD/PDF，旁注仍存在。旁注保存在 DayDream 本地数据中，不写入原 PDF。
- [ ] 未选中文字时使用选区翻译会提示先选择。无可读取文本的扫描 PDF 会提示先做文字识别，本轮不包含 OCR。

## D. 双栏全文翻译

- [ ] 三点菜单“在右侧显示全文翻译”：左侧原文、右侧译文，MD/PDF 都可用。
- [ ] 分隔线细且圆润，上下留白；拖动可调整宽度，长译文可独立滚动、选择复制。
- [ ] 翻译过程中能看到进度状态；关闭译文或取消翻译不会改动原文。
- [ ] 翻译过程中切换文档，旧译文不会出现在新文档中。

## E. 参考窗格与快捷键隔离

- [ ] 原侧栏右键笔记 →“在侧栏中打开”，左侧保留当前编辑，右侧打开所选 MD 或 PDF。
- [ ] 右侧有自己的侧栏、三点菜单和导出按钮；切换右侧笔记不会切换左侧笔记。
- [ ] 右侧可正常编辑 Markdown、自动保存、使用样式和工具条；PDF 可缩放、翻译、浏览。
- [ ] 拖动分隔线调整两侧宽度，左右内容保留。
- [ ] Option + Command + 左右箭头切换焦点；Markdown 光标有快速飞入动画，不直接瞬移。
- [ ] Control + Option + 左右箭头只切换当前窗格的历史，不与焦点快捷键冲突。
- [ ] 分别在左、右窗格和侧栏点击后使用复制、粘贴、格式、重置、缩放，操作目标正确。
- [ ] 右侧聚焦时 Command + W 关闭右侧笔记窗格，左侧笔记和应用窗口仍保留；单栏时只关闭当前笔记。
- [ ] 一侧重命名/移动/删除文件后，另一侧对应文档更新路径或关闭；保存冲突时不静默覆盖。
- [ ] 参考窗格存在时再打开 Finder 独立窗口，并切换回来，左右窗格快捷键仍有效。
