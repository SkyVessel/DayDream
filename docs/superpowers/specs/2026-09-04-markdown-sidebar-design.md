# DayDream Markdown 与嵌套侧栏设计

## 目标

在保留 DayDream 当前原生 `NSTextView` 编辑体验、平滑光标、双主题和缩放行为的基础上，加入：

- 所见即所得的四级标题、子弹列表、数字列表和 Todo 列表。
- 行首 Markdown 快捷语法输入后按空格立即转换，语法标记不再显示。
- 空段落输入 `/` 后出现命令菜单，支持方向键、Enter 和 Escape。
- 可折叠侧栏，能够创建、显示和选择可嵌套的文件夹与 Markdown 笔记。
- 左上角侧栏开关和新增菜单，使用 Morphicons 所支持的简洁 Lucide 线性图标造型。

## 数据与文件结构

用户资料存放在 `Application Support/DayDream/Library`。文件夹对应真实目录，笔记对应 UTF-8 `.md` 文件。首次启动时只创建空资料库；当前笔记在编辑后防抖自动保存，切换笔记和应用退出前立即刷新保存。

侧栏只展示目录和 `.md` 文件，按名称排序，文件夹优先。新建项目位于当前选中的文件夹；若选中的是笔记，则位于该笔记的父文件夹；没有选择时位于资料库根目录。新建项目使用不冲突的默认名称，并立即进入内联重命名。文件名会过滤 `/`、`:` 和空名称。

第一版嵌套通过“在选中的文件夹中新建”实现，不包含拖拽移动、删除和导入外部资料库；这些不是本次目标。

## 编辑器模型

编辑状态使用可见文本加段落级块属性，块类型为：

- `body`
- `heading(1...4)`
- `bullet`
- `numbered`
- `todo(checked: Bool)`

Markdown 标记不作为透明字符留在编辑器中。打开文件时解析支持范围内的 Markdown 为块属性；保存时由块属性重新生成标准 Markdown。因此点击、选择或移动光标不会重新显示 `#`、`-` 等标记，磁盘文件仍保持可移植的 Markdown。

`DayDreamTextView.applyTheme()` 改为按块类型重建视觉属性，避免当前整篇统一覆盖样式的行为抹掉标题和列表格式。编辑器继续使用 TextKit 1，避免重写现有选区、输入法和自定义光标。

## 输入行为

仅在段落开头、光标位于触发符之后且没有输入法 marked text 时转换：

- `# `、`## `、`### `、`#### ` → H1 至 H4
- `- ` 或 `* ` → 子弹列表
- `1. ` → 数字列表
- `[ ] ` 或 `[] ` → 未完成 Todo
- `[x] ` 或 `[X] ` → 已完成 Todo

回车规则：

- 标题末尾回车创建正文段落。
- 非空列表项回车延续同类列表。
- 空列表项回车退出列表并变为正文。
- Todo 延续时默认创建未完成项。

数字列表的序号根据同一连续列表的显示顺序动态计算。Todo 的方框由编辑器绘制并支持鼠标点击；完成项显示勾选和弱化正文。空标题显示淡色 `Heading 1` 至 `Heading 4` 占位文字，真实文本保持为空。

## 斜杠菜单

在空段落输入 `/` 时打开菜单，包含四级标题、子弹列表、数字列表和 Todo。菜单锚定在插入点附近。打开期间：

- 上下方向键移动选择。
- Enter 应用选中块类型并移除 `/`。
- Escape 关闭并保留普通编辑状态。
- 点击菜单项也可应用。

菜单第一版不提供文本搜索。存在 marked text 时不接管 Space、Enter 或方向键，保证中文输入法候选确认仍由系统处理。

## 界面结构

根界面由 SwiftUI 管理布局与资料库状态：左侧为约 250 pt 的侧栏，右侧为现有 AppKit 编辑器。侧栏关闭后编辑器占满窗口；开关固定在窗口左上角并保持可见。侧栏使用低饱和背景、细分隔线和紧凑树行，延续当前纸张式视觉，不复制参考图中的粗重文件图标。

图标使用 Morphicons 演示体系兼容的 Lucide 24×24 线性路径：侧栏开关、文件夹、文件、展开箭头和新增。由于 Morphicons 没有 Swift/macOS 绑定，不引入 JavaScript 运行时；路径作为原生 SwiftUI `Shape`/`Path` 渲染，并保留图标来源许可说明。

## 组件边界

- `WorkspaceStore`：扫描资料库、创建节点、重命名、读取与原子保存 Markdown。
- `WorkspaceNode`：稳定 ID、URL、节点类型和递归子节点。
- `WorkspaceView` / `SidebarView`：侧栏状态、选中状态、树展示和新增交互。
- `MarkdownDocumentCodec`：支持范围内 Markdown 与块模型的双向转换。
- `MarkdownEditingController`：快捷语法、回车规则、列表编号及块属性维护。
- `SlashCommandPanel`：菜单展示、定位与键盘选择。
- `DayDreamTextView`：保留输入、布局、绘制和光标职责，通过控制器处理块行为。

## 错误处理

文件创建、读取或保存失败时，界面显示非阻塞错误提示并保留编辑内容。写入采用同目录临时文件替换，降低文件损坏风险。外部删除当前文件时不静默覆盖，而是提示用户重新创建或选择其他笔记。

## 测试与验收

自动测试覆盖：

- 每种快捷语法的转换与标记移除。
- H1 至 H4、列表及 Todo 的 Markdown 解析/序列化往返。
- 标题和列表的回车延续/退出规则。
- 连续数字列表重新编号。
- 嵌套目录扫描、新建位置、名称冲突和 Markdown 原子保存。
- 主题或缩放重新应用后块类型不丢失。

人工验收覆盖：

- 左上角按钮开关侧栏，编辑区域随之自然伸缩。
- 创建多层文件夹和笔记并切换编辑，重启后结构与内容仍存在。
- `/` 菜单的键盘和鼠标操作。
- 点击 Todo、空标题占位、中文输入法、撤销/重做及 Cmd `+`/`-`。
- 明暗主题中的排版、图标和选中状态。
