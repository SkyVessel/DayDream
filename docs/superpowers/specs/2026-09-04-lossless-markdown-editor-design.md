# DayDream 无损 Markdown 设计

## 目标

DayDream 继续提供所见即所得编辑，但磁盘上的 UTF-8 `.md` 文件始终是唯一真相源。打开并保存而未修改的内容必须逐行保持原样；编辑只允许规范化真正改变的行，未识别语法不得因一次保存而丢失。

## 第一阶段：源文本保留层

加载文档时同时保留原始行与 DayDream 当前编辑模型生成的基准行。导出时将当前规范化结果与基准结果做稳定差异匹配：仍与基准相同的行写回原始文本，新增或修改的行写入当前规范化 Markdown。这样可以保留列表标记、原始序号、任务框大小写、HTML、空白与未知语法，并能在插入或删除行后继续识别后续未修改行。

源文本保留层不参与界面排版，也不改变现有 Markdown 块模型。它只负责最终输出选择，因此可独立测试并逐步替换。

## 后续阶段

- 将引用、围栏代码块、链接、图片、分隔线和 5–6 级标题加入编辑模型。
- 嵌套列表通过缩进层级表示；未知或暂不支持的多行结构以原始区块呈现。
- 粗体、斜体和任务列表输出标准 Markdown；颜色和高亮继续作为 HTML 扩展，但只输出有效 CSS 颜色值。
- 对复杂输入采用“未知即保留”，绝不猜测后重写。

## 验证标准

1. 任意已支持或未知 Markdown：打开后直接保存，内容与原文件完全一致。
2. 修改一行时，其他行保持逐字节一致。
3. 在文档中插入或删除行，未修改的后续行仍保持原样。
4. DayDream 新建的标题、列表、任务列表、粗体和斜体可被常见 Markdown 软件解析。
5. 所有现有编辑、保存、快捷键和视觉测试继续通过。
