# 搜索与页面功能：本轮测试清单

请先退出旧版，再打开项目根目录中的 DayDream.app。

## 搜索

- [ ] 按 ⌥Space，或点击左上角与历史按钮并列的放大镜；窗口应轻微上移并淡入。
- [ ] 输入已存在笔记的完整名称、部分名称、中文、不同大小写；前后带空格也应找到它。
- [ ] 连续快速修改搜索词，结果跟随最新输入；包含 PDF 的库中，文件名应先出现，选中项的预览随后加载。
- [ ] 上下键选择、Enter 打开、⌥Enter 在参考窗格打开均正常。

## Page

- [ ] 深色模式打开 `/` 菜单，Page 与 Link Page 图标应为浅色，浅色模式下应为深色。
- [ ] 输入 `/page` 并按 Enter，进入新笔记，第一行是一级标题 Untitled（已有同名文件时带编号），标题文字处于选中状态，可直接替换。
- [ ] 修改首行标题，稍停片刻，侧栏文件名应同步改变，光标不跳到文末，正文保留。
- [ ] 用 ⌃⌥← 返回来源笔记，原链接应显示更新后的名称，点击仍能打开新页面；重启后关系保持。
- [ ] 将标题改成已有笔记的名称，应提示重名，不能覆盖原来的笔记。清空标题时保留当前文件名。

只有本轮起通过 `/page` 新建的页面自动关联首行标题与文件名；普通笔记的标题不会触发自动改名。

## Link Page

- [ ] 输入 `/link` 或 `/link page`，选择 Link Page 并 Enter，出现“链接已有笔记”搜索框。
- [ ] 搜索现有笔记，上下键选择后 Enter：在原来的 `/link page` 位置插入蓝色下划线链接，不创建新笔记，也不立即跳走。
- [ ] 点击插入的链接可跳转，目标笔记的反向链接可找到来源。
- [ ] Esc 取消后保留原文；在参考窗格中同样可以插入链接。
