# DayDream 更新测试清单

对应上一轮已明确的 8 项需求。此后已收到《大更新提示词.md》；新一轮验收请使用同目录《大更新测试清单-2026-09-09.md》。

测试应用：`/Users/ty/Desktop/DayDream/DayDream.app`。请先保存并退出旧版本，再打开此应用。当前更改未推送 GitHub；本轮未启动软件，也未使用 Computer Use。

## 1. 默认语言
- [ ] 新用户设置默认显示英文。
- [ ] 已有用户选择的中文或英文保持不变，切换语言后重启仍保留。

## 2. Focus Mode 快捷键
- [ ] 默认按 Control + Option + F 开启句子淡化，再按一次关闭。
- [ ] 在 Settings 修改快捷键，新组合立即生效，重启后保留。

## 3. 列表与 Tab 自动补全
- [ ] 分别在数字列表、字母层级列表、bullet 和 checkbox 中输入英文单词前半部分；出现补全提示后按 Tab，补全单词，列表位置不变。
- [ ] 数字列表行首按 Tab，仍可缩进一级并显示字母编号。
- [ ] 没有补全提示时，在 bullet/checkbox 的文字中按 Tab，只缩进文字，不移动列表标记。

## 4. Ultra Focus 滚动
- [ ] 打开多页长文，Option + Command + ↑ 进入 Ultra Focus，键盘输入仍平滑居中。
- [ ] 鼠标滚轮或触控板上下滚动时，页面不会被拉回原光标位置；光标跟随视口中央文本行。
- [ ] 停止滚动后输入，文字出现在新的光标位置。
- [ ] Option + Command + ↓ 退出后恢复普通滚动。
- [ ] 与普通 Focus Mode 叠加时，中央光标所在句子的淡化状态正确更新。
- [ ] 与 Retype 叠加时，滚动不跳过练习进度，继续输入仍按原练习位置进行。

## 5. 下划线与删除线
- [ ] 选中文字后，Command + U 切换下划线，Command + Shift + X 切换删除线。
- [ ] 无选区时使用快捷键，随后输入的文字带对应样式，再按一次恢复。
- [ ] 在工具条设置中可以选取下划线、删除线，并通过工具条应用。
- [ ] 保存并重新打开 Markdown，样式仍保留；更换主题后显示正常。
- [ ] 在设置中修改这两个快捷键后，新组合正常生效。

## 6. 选区重置样式
- [ ] 选中带字体、粗斜体、颜色、高光或横线样式的单词，按设置中的 Reset 快捷键（默认 Command + 3），恢复默认文字样式。
- [ ] 只重置选区，左右未选文字和列表/标题结构保持不变。
- [ ] 无选区时重置，随后输入使用默认样式。
- [ ] 重置选区后撤销、重做，内容和样式正确恢复。

## 7. PDF 和侧栏导入
- [ ] 从右上角导出菜单将含标题、列表、样式和本地图片的长 Markdown 导出 PDF，检查全部页面、末尾内容与图片。
- [ ] 从导入菜单导入 PDF，在侧栏出现独立带 PDF 标识的文件，点击后可滚动浏览。
- [ ] 切换 PDF 与 Markdown，编辑器、字数与导出选项正确切换；PDF 内容不被 Markdown 保存覆盖。
- [ ] 从 Finder 拖入 Markdown、PDF、Word 到侧栏空白处，导入到库根目录；拖入文件夹行时导入该文件夹。
- [ ] 同时拖入多个文件，均成功导入；重名文件生成新名称，原文件保持不变。
- [ ] PDF 在侧栏重命名、复制、移动后仍正常浏览，并保持 .pdf 扩展名。
- [ ] 原有库内文件拖动仍是移动操作。

## 8. Finder 独立 Markdown 窗口
- [ ] 将 Markdown 拖到 DayDream 应用图标，打开独立窗口，顶部居中显示文件名。
- [ ] Finder 右键 Markdown → 打开方式，可以选择 DayDream。
- [ ] 修改文字、使用样式快捷键、复制粘贴后关闭窗口；用其他文本编辑器确认原文件已保存。
- [ ] 连续打开不同 Markdown，窗口各自编辑和保存，不串到主工作区笔记。
- [ ] 同一文件再次打开时聚焦已有独立窗口，避免多个窗口互相覆盖。
- [ ] 外部编辑器同时修改文件时，DayDream 提示保存冲突，可选择读取磁盘版或保留当前修改。
