# DayDream 本轮测试清单

测试包：项目根目录 `DayDream.app`。请先正常退出正在运行的旧版，再打开此测试包。

本轮做了源代码与测试目标编译检查，没有启动软件、使用 Computer Use 或执行交互测试；没有推送 GitHub。以下勾选项留给你实际测试。

## 1. 翻译清理

- [ ] 打开以前有旁注翻译的笔记和 PDF，旁注与旁注留白已消失；笔记正文、文件和原有文字高亮保留。
- [ ] 设置、三点菜单、右键菜单和 `/` 菜单中没有翻译功能。输入 `!!` 不再触发翻译。
- [ ] 关闭文件并重新打开，旁注不会回来。

已按授权清理 33 条旁注记录，来自 2 个单独的 JSON 文件。没有删除笔记或修改正文中已经存在的内容。

## 2. 启动与临时预览（优先测试）

- [ ] 退出 DayDream 后，从 Finder 把 MD 拖到应用图标：只打开对应临时预览，不出现空白 Library 窗口。
- [ ] 同样测试 PDF、同时拖入两个文件，以及通过“打开方式 → DayDream”打开。
- [ ] 在已有主窗口时拖入文件：保留原窗口，只新增对应预览；重复打开同一文件复用预览。
- [ ] 普通启动应用仍能打开笔记库；关闭所有窗口后点击 Dock 图标可以重新打开笔记库。“工作区 → 打开笔记库”也可使用。
- [ ] 临时 MD 修改、关闭、重新打开后内容已保存；窗口标题仍显示文件名。设置窗口、快捷键菜单仍可正常打开。

## 3. PDF 原样显示

- [ ] 用同一份 PDF 对照 macOS 预览查看，小字和细线清楚，底色及图片颜色与原文件一致。
- [ ] 切换 DayDream 深色/浅色模式，PDF 页面不反色、不模糊。
- [ ] 分别在主窗口、参考窗格和临时预览中检查；缩放、滚动和文字选择正常。

## 4. 参考窗格与专注状态

- [ ] 在右侧打开笔记，右侧只显示文档，没有自己的文件侧栏、历史按钮、导出按钮、三点按钮或字数按钮。
- [ ] 打开 Focus Mode，两侧同步应用；Ultra Focus 进入/退出也同步，界面按钮统一隐藏/恢复。
- [ ] 点击左右编辑区，或用 `⌥⌘← / ⌥⌘→` 切换，只有当前获得焦点的编辑区显示光标。
- [ ] 右侧获得焦点时使用侧栏快捷键，操作的是主侧栏；右侧不会新增一个侧栏。
- [ ] Ultra Focus 下滚动、输入、工具 bar 保持可用；调整分栏宽度不会改变 PDF 的原始颜色。

## 5. 文件搜索

- [ ] DayDream 在前台时按 `⌥Space`，出现类似 Spotlight 的搜索浮窗，输入焦点直接位于搜索框。
- [ ] 输入中文、英文或文件路径中的部分名称，可以找到当前笔记库中的 MD/Markdown/PDF；快速修改搜索词不会留下旧结果。
- [ ] 用上下方向键切换结果，被选中的一条展开显示文件开头；长列表会跟随选中项滚动。
- [ ] 按 `Enter` 在主窗格打开；按 `⌥Enter` 在参考窗格打开。原来正在编辑的笔记已保存。
- [ ] 按 `Esc` 取消后回到原编辑位置；点击其他窗口也能关闭搜索，不抢回焦点。
- [ ] 空结果、空白笔记、没有可提取文字的 PDF 均不会卡住。设置中的搜索快捷键可修改。

当前搜索按文件名和相对路径匹配，范围为当前笔记库；不是全电脑搜索或全局后台快捷键。

## 6. 双链与 /page

- [ ] 建立名为 `测试页` 的笔记，在另一篇中输入 `[[测试页]]`：完成后显示蓝色下划线文字，点击跳转。
- [ ] 输入 `[[文件夹/测试页|显示名称]]`，检查显示名称、跳转，以及关闭后重新打开仍正确。
- [ ] 在列表和标题里插入笔记链接，原来的列表缩进、计数、标题样式保持正常。
- [ ] 在目标笔记的三点菜单打开“反向链接”，能看到来源笔记，点击可返回来源。
- [ ] 输入 `/page` 并按 Enter，当前行留下关联链接，立刻进入新笔记；新文件同时出现在主侧栏。
- [ ] 用 `⌃⌥←` 返回原笔记，用 `⌃⌥→` 前进；原笔记中的链接已保存且可再次打开。
- [ ] 在参考窗格中使用 `/page`，也能创建、跳转和返回；两个窗格不会同时出现光标。
- [ ] 指向不存在笔记或无法唯一确定的同名笔记时有提示，不会打开错误文件。代码块中的 `[[文字]]` 保持代码文字。

这轮没有增加重命名时批量改写所有引用的功能；同名笔记请使用包含文件夹的链接目标。
