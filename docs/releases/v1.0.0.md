# DayDream v1.0.0

DayDream 首个正式版本：一款以键盘操作、轻量排版和专注写作为核心的原生 macOS Markdown 编辑器。

## 功能

- Markdown 编辑与 `/` 样式检索，支持标题、列表、任务清单、引用、代码块、分隔线。
- 两条可自定义工具条，支持系统及导入字体、粗斜体、文字颜色、高光和段落样式；支持选区应用、取消及撤销/重做。
- 弹性显现与可调 Falling Text 打字特效。
- 可拖动、等比缩放的图片/视频卡片，以及带站点图标的行内网页链接。
- Focus、Ultra Focus、Retype、字数统计及 Markdown / Word 导入导出。

## 本版修复

修复列表额外标记、列表缩进冲突、工具条确认时机、默认样式重置、复制/剪切/粘贴、引用竖线间隙、多图片拖动、图片变形、样式撤销、高光颜色来源、站点图标比例和窗口模式顶部按钮对齐。

## 安装与兼容性

- 平台：macOS 14+，Apple Silicon（arm64）。
- 提供 DMG、ZIP 和 SHA-256 校验文件。
- 默认重置快捷键为 ⌘3；用户已有的自定义绑定与设置保留。
- 当前包采用临时签名，尚无 Developer ID 分发签名或 Apple 公证。首次启动可能需要通过 macOS“隐私与安全性”确认。
- 字体、颜色、高光及媒体的跨编辑器外观取决于对 HTML/CSS/视频的支持；普通 Markdown 结构保持可读。

## 验证

用户已完成本版本功能与视觉验收。发布前进行针对性自动测试、Release 构建、包结构与签名完整性检查，不启动应用。
