# DayDream

一款安静的 macOS 原生 Markdown 编辑器（原型）。study tool 的附属项目。

## 设计规则

- 所有颜色低饱和度
- 界面只有编辑器本身：没有任何按钮、栏、装饰
- 光标不闪烁、不瞬移，以平缓的缓动动画移动

## 双主题（跟随系统外观自动切换）

| | 亮色 | 暗黑 |
|---|---|---|
| 背景 | 接近白但不刺眼 `#FAFAF8` | 枪灰 `#2A3438` |
| 文字 | 柔和墨色 `#3D3D3B` | 不刺眼的白 `#E7E4E0` |
| 光标 | 淡蓝 `#9EC4E8` | 淡粉 `#F1BEC9` |

字体：苹果系统字体（SF），词距较宽，行高 1.55。

## 运行

```bash
swift run                 # 直接运行
./Scripts/package-app.sh  # 打包成 DayDream.app 并启动
```
